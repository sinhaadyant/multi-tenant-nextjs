Step 3: Set Up Database Schema with Prisma
Goal: Design and implement the complete database schema for the multi-tenant admin system.
Implementation Details:

Design tables: Users, Tenants, Roles, Modules, Permissions, etc.
Set up relationships and foreign keys
Configure indexes for performance
Add audit fields (created_at, updated_at, created_by, etc.)
Implement soft delete pattern

Database Tables with Fields:

tenants - Tenant management
- id: string (UUID, primary key)
- name: string
- domain: string (unique)
- settings: JSON (tenant-specific configurations)
- status: enum ('active', 'inactive', 'suspended')
- subscription_plan: string
- subscription_end: datetime (optional)
- created_at: datetime
- updated_at: datetime
- deleted_at: datetime (optional, for soft delete)

users - User accounts with tenant association
- id: string (UUID, primary key)
- tenant_id: string (foreign key to tenants.id)
- first_name: string
- last_name: string
- email: string (unique)
- password_hash: string
- phone: string (optional)
- profile_image: string (optional)
- status: enum ('active', 'inactive', 'pending')
- last_login: datetime (optional)
- created_at: datetime
- updated_at: datetime
- created_by: string (foreign key to users.id, optional)
- deleted_at: datetime (optional)

roles - Role definitions supporting both global and tenant-specific roles
- id: string (UUID, primary key)
- tenant_id: string (foreign key to tenants.id, optional for global roles)
- name: string
- description: string (optional)
- type: enum ('global', 'tenant')
- created_at: datetime
- updated_at: datetime
- deleted_at: datetime (optional)

user_roles - Many-to-many user-role relationship
- user_id: string (foreign key to users.id)
- role_id: string (foreign key to roles.id)
- created_at: datetime

modules - Application modules/features
- id: string (UUID, primary key)
- name: string
- description: string (optional)
- icon: string (optional)
- order_index: int
- parent_id: string (foreign key to modules.id, optional for submodules)
- created_at: datetime
- updated_at: datetime
- deleted_at: datetime (optional)

permissions - Granular permissions (CRUD + ViewAll)
- id: string (UUID, primary key)
- role_id: string (foreign key to roles.id)
- module_id: string (foreign key to modules.id)
- submodule_id: string (foreign key to modules.id, optional)
- can_create: boolean (default false)
- can_read: boolean (default false)
- can_update: boolean (default false)
- can_delete: boolean (default false)
- can_view_all: boolean (default false)
- created_at: datetime
- updated_at: datetime

support_tickets - Support ticket system
- id: string (UUID, primary key)
- tenant_id: string (foreign key to tenants.id)
- user_id: string (foreign key to users.id)
- title: string
- description: text
- priority: enum ('low', 'medium', 'high', 'urgent')
- status: enum ('open', 'in_progress', 'resolved', 'closed')
- assignee_id: string (foreign key to users.id, optional)
- created_at: datetime
- updated_at: datetime
- deleted_at: datetime (optional)

ticket_replies - Ticket conversation threads
- id: string (UUID, primary key)
- ticket_id: string (foreign key to support_tickets.id)
- user_id: string (foreign key to users.id)
- content: text
- is_internal: boolean (default false)
- created_at: datetime

audit_logs - System activity tracking
- id: string (UUID, primary key)
- user_id: string (foreign key to users.id, optional)
- action: string
- module: string
- entity_id: string (optional)
- before_data: JSON (optional)
- after_data: JSON (optional)
- ip_address: string
- user_agent: string
- created_at: datetime

user_sessions - Session management and device tracking
- id: string (UUID, primary key)
- user_id: string (foreign key to users.id)
- refresh_token: string
- device_fingerprint: string
- ip_address: string
- user_agent: string
- expires_at: datetime
- created_at: datetime

file_uploads - File metadata tracking
- id: string (UUID, primary key)
- tenant_id: string (foreign key to tenants.id)
- user_id: string (foreign key to users.id)
- entity_type: string (e.g., 'ticket', 'user')
- entity_id: string
- file_name: string
- original_name: string
- mime_type: string
- size: int
- path: string
- created_at: datetime
- deleted_at: datetime (optional)

Indexes and Constraints:
- Unique constraints on emails, domains
- Indexes on foreign keys, status fields, created_at for performance
- Cascade deletes where appropriate (e.g., user_roles on user delete)
