## **Permission-Based Data Scope Implementation**

### **Core Data Scope Rules:**
```typescript
// API Behavior Examples:

// GET /api/users
// Superadmin: Returns all users across all tenants
// canViewAll: Returns users within same tenant  
// canRead: Returns only the user's own profile

// POST /api/users
// Requires canCreate permission
// Tenant scope: Can only create users in same tenant
// Field validation based on permissions

// PUT /api/users/:id
// canUpdate + canViewAll: Can update any user in tenant
// canUpdate only: Can update only own profile
// Superadmin: Can update any user across tenants

// DELETE /api/users/:id
// canDelete + canViewAll: Can delete any user in tenant
// canDelete only: Cannot delete (no access to others)
// Superadmin: Can delete any user across tenants
```

### **Data Scope Middleware:**
```typescript
interface DataScopeContext {
  userTenantId: string;
  isSuperadmin: boolean;
  canViewAll: boolean;
  canCreate: boolean;
  canRead: boolean;
  canUpdate: boolean;
  canDelete: boolean;
  userId: string;
}

const applyDataScope = (query: any, context: DataScopeContext) => {
  if (context.isSuperadmin) {
    return query; // No filtering for superadmin
  }
  
  if (context.canViewAll) {
    return query.where({ tenantId: context.userTenantId });
  }
  
  if (context.canRead) {
    return query.where({ 
      OR: [
        { userId: context.userId },
        { createdBy: context.userId }
      ]
    });
  }
  
  throw new Error('Insufficient permissions');
};
```

## **Implementation Summary and Key Requirements**

### **Permission-Based Data Scope Implementation**

All APIs must implement the following data scope behaviors:

#### **Data Scope Levels:**
1. **Superadmin**: Can access ALL data across ALL tenants
2. **canViewAll**: Can access all data within their own tenant
3. **canRead**: Can only access their own data

#### **Required Data Scope Middleware:**
```typescript
interface DataScopeContext {
  userTenantId: string;
  isSuperadmin: boolean;
  canViewAll: boolean;
  canCreate: boolean;
  canRead: boolean;
  canUpdate: boolean;
  canDelete: boolean;
  userId: string;
}

const applyDataScope = (query: any, context: DataScopeContext) => {
  if (context.isSuperadmin) {
    return query; // No filtering for superadmin
  }
  
  if (context.canViewAll) {
    return query.where({ tenantId: context.userTenantId });
  }
  
  if (context.canRead) {
    return query.where({ 
      OR: [
        { userId: context.userId },
        { createdBy: context.userId }
      ]
    });
  }
  
  throw new Error('Insufficient permissions');
};
```

1. **Data Scope Filtering** - Based on user permissions (superadmin/canViewAll/canRead)
2. **Tenant Isolation** - Automatic tenant boundary enforcement
