## 🚀 Usage

1. **Start the development server**:
   ```bash
   npm run dev
   ```

2. **Visit the landing page**:
   - Navigate to http://localhost:3000/
   - Explore the three tabs: Overview, Features, Demo

3. **Test the demo**:
   - Click "Try Demo" or use the demo credentials
   - Experience different user roles and permissions

4. **Access admin panel**:
   - Use SuperAdmin credentials for full access
   - Explore tenant management and role creation
