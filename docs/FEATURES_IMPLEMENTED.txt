Project Features Implemented

Authentication & Session
- JWT-based authentication with access and refresh tokens
- Configurable access token expiry (env: JWT_ACCESS_EXPIRES_IN)
- Refresh tokens with standard and "Remember Me" durations
- Automatic token refresh via API response interceptor (tenant API)
- Redux is the source of truth for tokens; storage used only as fallback
- Session validation on tenant login; graceful redirect after validation
- SuperAdmin authentication and role enforcement

Multi-Tenancy
- Tenant slug-based routing: src/app/[tenantSlug]/*
- Tenant-aware API routes: src/app/api/tenant/[tenantSlug]/*
- Middleware for authentication and module access checks

Authorization & Permissions
- Roles and granular per-module permissions
- Dynamic permissions context + Redux slices for permissions
- Permissions and modules bundled in /me?includeModules=true

Modules & Navigation
- Modules table, ordering, visibility, and tenant visibility flags
- Modules hydrated into Redux for tenant navigation

SuperAdmin Portal
- Manage tenants, users, modules, support tickets, and reports
- Dedicated pages under src/app/superadmin/*

Audit Logs
- Request-scoped audit entries with helpers
- E2E coverage for key audit flows

Support Tickets
- CRUD operations, file uploads, created_by tracking
- Tenant-scoped storage under public/uploads

Reports
- Report status lifecycle and data fetching hooks

Notifications
- Notification hooks and UI components
- Toast notifications for auth/session states

Backup & Import
- Backup/export and import flows with E2E tests

UI/UX
- Tailwind-based admin UI with reusable components (DataTable, notifications)
- Confirm modal and theme demo pages

API & Documentation
- Swagger UI integration (src/components/SwaggerUI.tsx)
- API documentation under docs/api/

Testing
- Jest API tests and utilities under src/__tests__ and scripts/test-scripts
- Cypress E2E and component tests (cypress/ and tests/e2e)

Tooling & Scripts
- Setup/maintenance scripts in scripts/ (assign permissions, add modules, activate superadmin, etc.)

Security
- Password hashing with bcrypt
- JWT verification with detailed dev logs

Recent Improvements
- Added automatic token refresh in src/lib/api.ts with Redux integration
- Updated src/hooks/useReduxAuth.ts to prefer Redux tokens and refresh before profile fetch
- Login flow (src/app/[tenantSlug]/login/page.tsx):
  - Uses Redux for token retrieval during session check
  - Removes direct token persistence on login; relies on Redux state
  - Supports redirecting to pre-login target via sessionStorage key redirectAfterLogin
- Response interceptor retries original requests after successful refresh
- Clearing auth now clears Redux state and storage fallbacks
